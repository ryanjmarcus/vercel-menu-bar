## [1.0.0] - 2026-01-30

### Added

- Initial release
- Live deployment monitoring from the menu bar
- Real-time build status with live duration counters
- Support for building, ready, error, and cancelled deployment states
- Quick actions to open deployments in Vercel
- GitHub integration with direct links to commits and branches
- Project selector to focus on specific projects
- Configurable refresh intervals
- Fast refresh mode for active deployments
- Deployment detail view with full information
- Environment settings links
- Domain list with copy functionality
- Author avatars from GitHub
- Right-click menu on status item to quit app
